# team-room-submit — запрос в «Комнату команды» из чата Hermes

Навык для Hermes: человек пишет «в комнату cafe: сверстать меню на неделю», и
запрос уходит в локальное приложение «Комната команды» тем же путём, каким его
создаёт кнопка в интерфейсе. Приложение работает на `127.0.0.1` (по умолчанию
порт 8777); ничего наружу не отправляется.

## Когда применять

Только по явной просьбе человека и **только** если в сообщении названа комната:
«в комнату <id>: …», «поставь в комнату <id> задачу …», «отправь в <id>: …».
Без названной комнаты или при сомнении — спросить, ничего не отправлять.

## Как отправить

```bash
python scripts/submit_request.py --room cafe --text "Сверстать меню на неделю"
```

* `--room` — id комнаты (`cafe`, `laundry`, `freight`, …). Список: `GET /api/rooms`.
* `--text` — дословный текст запроса (до 20 000 знаков). Ничего не переписывай и
  не сокращай: руководитель комнаты разбирает формулировку человека.
* `--title` — необязательный заголовок (≤120 знаков).
* `--port` — порт приложения (по умолчанию 8777 или `TEAMROOM_PORT`).
* `--client-id` — ключ идемпотентности; по умолчанию sha1 от (комната, текст),
  поэтому повтор той же команды в течение минуты не создаст второй запрос.

Скрипт печатает одну строку JSON: `{ok, room, request_id, title, url, duplicate}`
или `{ok: false, error, reason, how}`.

## Что сказать человеку

* Успех: «Запрос «<title>» в комнате <id> создан — открыть: <url>».
* `connection refused` / `ok: false`: приложение не запущено. Скажи прямо:
  «Комната команды не запущена — откройте start-team-room.cmd» и не выдумывай
  результат.
* `duplicate: true`: запрос уже был отправлен минуту назад — второй не создан.

## Чего не делать

* Не писать в профили Hermes, не менять модели и разрешения — навык только
  создаёт запрос через публичную ручку приложения.
* Не отправлять вложения и не читать личные файлы.
* Не вызывать ручки, кроме `GET /api/rooms` и `POST /api/rooms/{id}/requests`.
* Приложение может быть в песочнице на другом порту — тогда `--port` явно, и
  это тестовый запуск, а не рабочая комната.
