# Изменения

## 1.0.1 — 2026-11-04

Исправления выбора модели участника.

* **Выбор модели подменялся.** Клик по любой модели в списке выбирал последнюю модель провайдера
  (`deepseek-v4-pro` вместо `deepseek-v4.1-flash:1017`, `claude-fable-5-1` вместо `claude-sonnet-5-5`).
  Теперь выбирается именно та строка, по которой кликнули.
* **Список моделей раскрывается сразу** при любом провайдере, в поле видна текущая модель,
  есть стрелка раскрытия; `Esc` сворачивает список.
* **Из выбора модели убран микрофон** (и правило: поля выбора диктовку не получают).
* **Сервер не принимает «ближайшую» модель**: регистр и похожие названия не склеиваются;
  при неверном id приходит 400 с подсказками. В ответе сохранения есть эхо `applied`.
* **Значения «по умолчанию»** берутся из конфига самого участника; уровень мышления делегирования
  больше не выдаётся за уровень агента.
* При перезапуске карточки на новой модели выбор закрепляется до повторного захвата.

## 1.0.0 — 2026-11-03

Первый публичный выпуск.

**Установка**
* одна команда PowerShell: скачивает релиз, ставит приложение и модуль «Командные
  комнаты» в Hermes Desktop, поднимает сервер и открывает страницу (`install.ps1`);
* повторная установка ничего не дублирует, `-Uninstall` убирает за собой;
* нужен только Python 3.11+ (стандартная библиотека), git не требуется;
* приложение ставится в `%LOCALAPPDATA%\\TeamRoom`, данные — в `data/` рядом.

**Комнаты и работа**
* комнаты с оркестратором и критиком, дорожная карта, бэклог с фильтрами, журнал;
* запросы: постановка, уточнения, ответ команды, согласование критиком, история;
* отчёты: блоки, таблицы, графики, график связей, выгрузка в HTML и Markdown;
* поиск по комнате и палитра команд (`Ctrl+K`);
* диктовка голосом (локальное распознавание) и словарь терминов.

**Платформа**
* сервер на стандартной библиотеке Python 3.11+, интерфейс без сборки и без CDN;
* песочница: работа с настоящей доской только на чтение, запись — в копию;
* модуль «Командные комнаты» для Hermes Desktop и сторож, который держит его живым;
* демо-стенд на выдуманных данных (`start-demo-room.cmd`).

**Переносимость**
* никаких путей автора: корень Hermes, Vault и `hermes` CLI определяются сами
  (`HERMES_HOME`, `%LOCALAPPDATA%`, `~/.hermes`, `PATH`), любую настройку можно
  переопределить переменными окружения;
* если хранилища Obsidian нет — приложение работает без зеркала и подсказывает
  `TEAMROOM_VAULT_DIR`;
* если Hermes CLI не найден — комната работает в режиме просмотра, ошибки записи
  объясняются по-русски, без трассировок;
* без `faster-whisper` диктовка сообщает «не установлено», остальное работает;
* `tools/portability_check.py` проверяет оба сценария на «чистой машине».
